# My Car Dealership

#Description
-This is my Java car dealership project that reads cars from inventory.csv and lets the user search and view them.


# Features
- See all vehicles
- Search by Price
- Search by make and moodel
- Search by year
- Search by color
- Search by mileage
- Search by vehicle type
- add a vehicle
- Remove a vehicle

## How to Run
- Open the project in IntelliJ
- Run Program.java
- Pick a number from menu

## Project Structure
- Vehicle.java - one car
- Dealership.java - list of cars and search methods
- DealershipFileManager.java - reads and saves inventory.csv
- UserInterface.java - menu and user input
- Program.java - starts the program
